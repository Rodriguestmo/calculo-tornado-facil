# Cálculo Tornado Fácil (PT-BR)

Tradução pública e gratuita para português brasileiro de *Calculus Made Easy*, de Silvanus P. Thompson (1910).

**Site:** https://rodriguestmo.github.io/calculo-tornado-facil/

Projeto sem fins lucrativos. **Não é permitido comercializar.**

## Desenvolvimento local

```bash
python3 -m venv myenv && source myenv/bin/activate
pip install -r requirements.txt
python3 compile_templates.py
python3 -m http.server 8765 --directory public
```
